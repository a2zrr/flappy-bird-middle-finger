# Flappy Bird Game in Java

## Overview
Flappy Bird is a simple 2D game built using Java and the Swing framework. The objective of the game is to control a bird that avoids colliding with pipes while staying in the air. The bird can be controlled by pressing the spacebar to make it fly. The game continues until the bird hits a pipe or falls below the screen. The game features a scoring system and a restart button upon game over.

## Features
- **Bird Movement**: The bird is controlled by the spacebar to move up, with gravity pulling it down.
- **Pipes**: Pipes are randomly placed and move from right to left, and players need to navigate the bird through the gaps.
- **Score System**: Score increases as the bird successfully passes between pipes.
- **Game Over**: When the bird hits a pipe or falls off the screen, the game ends and displays the score with an option to restart.

## Requirements
- **Java 8** or higher.
- IDE or text editor (e.g., IntelliJ IDEA, Eclipse, VSCode) to run Java projects.
